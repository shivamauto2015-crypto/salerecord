AUTOPARTS SALES MANAGER
=======================

HOW TO RUN
1. Extract the ZIP file (autoparts-sales-manager.zip).
2. Open the extracted "autoparts-sales-manager" folder.
3. Double-click index.html (Chrome or Edge recommended).
4. Start adding challans.

FEATURES
- Multiple spare parts in one challan
- Fast Enter-key navigation: Challan Number -> Sale Date -> Customer Name -> Remarks -> Part Name -> Part Number -> Qty -> Rate -> Save
- Auto-focus on first field when adding another part row
- Trash/delete icon button on each part row
- Print button on New Challan form (opens a printer-friendly version in a new tab)
- Automatic subtotal, discount and net amount calculations
- Discount as rupees or percentage per item
- Search and date filtering
- Edit and delete challans
- Dashboard summary
- Offline Excel export with two sheets: Challan Summary and Part Details
- JSON backup download and restore
- Browser LocalStorage persistence (autoparts_sales_v1)

IMPORTANT DATA NOTE
Data is stored in LocalStorage in the browser and on the device where you use the app.
Do not clear browser site data unless you have a JSON backup.
All files including SheetJS (xlsx.full.min.js) are bundled locally for offline use.

TECHNOLOGY
HTML, CSS, JavaScript, JSON (LocalStorage + JSON import/export), SheetJS XLSX.
